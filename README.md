Professional portfolio featuring self-directed case studies in **Sales, Marketing, Project Coordination, and Business Operations**.

**Website:** https://aakashgajera.github.io/  
**LinkedIn:** https://www.linkedin.com/in/aakashgajera

## Published case studies

1. **B2B Lead Generation & Outreach Playbook** — fictional prospecting workflow, outreach and CRM demonstration.
2. **Sales Pipeline & CRM Dashboard** — Excel analysis of 40 fictional opportunities and a separate five-deal HubSpot demonstration.

Both projects include downloadable **PDF case studies** and **Excel evidence files**. These are independent simulations, not client engagements or actual business results.

## Website files

- `index.html` — website content and download links.
- `styles.css` — website styling.
- `script.js` — interactive behavior.
- `projects/` — PDFs and Excel workbooks linked from the project cards.

## Publish on GitHub Pages

Upload **all files and the `projects` folder together** to the root of the `main` branch. Under **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**. After deployment, verify each **Read case study** and **Excel evidence** link.

The `projects` folder must preserve its name and all four files; otherwise the website download links will not work.
