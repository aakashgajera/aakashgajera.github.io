AAKASH GAJERA — PORTFOLIO WEBSITE

This package is ready for GitHub Pages. No coding is required.

BEFORE PUBLISHING
- The LinkedIn button currently points to the LinkedIn home page, not your personal profile. Once you share your actual LinkedIn profile URL, it can be updated.
- There is intentionally no profile photo and no resume.
- The two case studies and supporting Excel workbooks are included under projects/.
- Check the files for information you are comfortable sharing publicly.

PUBLISH ON GITHUB
1. Open your repository aakashgajera/aakashgajera.github.io.
2. Select Add file > Upload files.
3. Upload index.html, styles.css, script.js, AND the projects folder with all four project files. (Do not upload the enclosing aakash_portfolio_site folder.)
4. Commit changes.
5. Open Settings > Pages > Build and deployment.
6. Choose Deploy from a branch; Branch: main; Folder: /(root); Save.
7. Wait for deployment, then visit https://aakashgajera.github.io.

If the browser upload doesn't preserve the projects folder, open projects/ in GitHub and upload those four files there separately.
